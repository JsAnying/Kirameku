# 匿名反馈

访客从全站左侧的“反馈”按钮提交类型、正文和可选联系方式，无需登录。
不采集或保存来源页面。正文按纯文本显示，反馈内容和联系方式仅管理员可查看。

后台入口为“反馈管理”（`/feedback/index`），支持类型/状态筛选、分页、详情、状态和内部备注更新、确认删除。

## 上线

1. 部署新的后端代码并重启。现有 `init_db()` 会创建缺少的表；也可预先在 PostgreSQL 执行 `Kirameku-backend/migrations/20261108_add_feedback.sql`。两种方式均不删除已有表和数据。
2. 分别构建、部署 Next.js 前台及 Vue 管理后台。后台菜单为静态路由模块，无需数据库菜单配置。
3. 确保 `/api/feedback` 及其子路径沿用 `/api/` 反向代理规则。
4. 从前台提交一条测试反馈，在后台检查筛选、状态和备注保存。

公开接口仅 `POST /api/feedback`，管理接口位于 `/api/feedback/admin` 并检查管理员身份。
默认按客户端 IP 每分钟最多 3 次提交，IP 仅在进程内短暂用于限频，不写入数据库。反向代理须正确覆盖客户端地址头，Uvicorn 仅信任实际代理地址。当前为单进程限频；多 worker 部署应在网关统一限频。

本地现有后端使用临时 SQLite 测试数据库；本地提交不会同步到正式 PostgreSQL。
